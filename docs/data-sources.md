# 数据来源与判断边界

联网部分由 Codex 当前可用工具完成，代码本身不运行爬虫、不调用模型 API。来源是公开可读网页、公开历史文献或档案；是否可访问取决于当前网络和站点状态。登录受限、读取失败及只有摘要的页面只保留线索。

| 来源 | 可以支持什么 | 不能直接推出什么 |
| --- | --- | --- |
| 原始文献、固定报刊版面 | 某日期或版期已有该词及相应含义 | 全网首次、作者一定首创 |
| 当前网页自述发布时间 | 候选日期和追查方向 | 旧日期对应的内容当时未被修改 |
| 历史存档 | 目标词至迟在快照日期已存在 | 快照日期就是首发日期 |
| 转载、后期回忆、词源综述 | 引用链和历史事件线索 | 被引用原作已经实际核验 |
| 搜索摘要 | 发现候选URL、检索线索 | 摘要等于原文、命中数等于热度 |
| Google Trends CSV | 给定查询、地域和时间范围内的相对搜索兴趣 | 绝对搜索量、跨范围可直接相加的统一指数 |
| 通用 CSV | 文件声明的时间序列指标 | 无来源元信息时的全网趋势 |

Google Trends 的值经过归一化，导入时保留整个序列的指标和查询范围，不拼接出“全网指数”。`<1` 是低于阈值，不是零；缺失值不插值。周／月聚合值只能对应原始完整区间。

可核对的官方说明：[Google Trends 导出数据](https://support.google.com/trends/answer/4365538?hl=en-GB)、[Google Trends 数据说明](https://support.google.com/trends/answer/4365533?hl=en)、[Arquivo.pt 历史搜索说明](https://sobre.arquivo.pt/en/help/search-2/)、[Codex Skills](https://developers.openai.com/codex/skills/)。

第一版不承诺已删除网页、未索引内容或历史封闭平台的召回率。需要论证“最早”的结论始终限定为本次实际检索找到并核验的范围；每次保留未解决线索，供下一轮补充。
