# 深度溯源 · term-history

**中文简介：** 中文优先的 Codex Skill，用可追溯证据调查词条早期出处、传播时间线和指定数据源内的热度变化。

**English overview:** A Chinese-first Codex skill for tracing the earliest verifiable records of a term, its spread, and its popularity within a specified data source.

## 使用 / Usage

技能本体在 `.agents/skills/term-history/`；辅助脚本使用 Python 3.9+，无额外 pip 依赖。

The skill lives in `.agents/skills/term-history/`; helper scripts require Python 3.9+ with no extra pip packages.

```text
python .agents/skills/term-history/scripts/term_history.py --help
```
